Project and Purpose: Garden Manager - Will help organize and keep gardening needs in one place, based on user inputs

Name: Jake Phung

Technologies Used: jGrasp/Java

Preqreuisited: Installed jGrasp, as well as imported scanner/arraylist (imports are done in the code)

Installation: Find jGrasp's official site and download near top left. Find which download suits you best. Open Java file attached to file and it should open. Otherwise, copy code and run in a platform which can run Java

Configuration: None needed

Running the Application: When Garden Manager is open, navigate to the top of the screen. The green cross checks for any bugs. The little red-person running will run the code

Trying Sprint 1: Follow the program's given instructions to navigate via user inputs. If an error occurs, end run and try again

Known Limitations: Few error-cases or restraints to what can be typed outside of what is allowed by default
